# Manris Risk Management Context

This context defines the project language for Manris risk management workflows. Use these terms consistently in user-facing workflow design and product discussions.

## Language

**Transaksi Pemantauan**:
A semester monitoring record that captures the act of monitoring an existing risk version and links the monitored source version to the resulting version created after finalization.
_Avoid_: reassessment transaction, monitoring record, risk monitoring row

**Status Risiko**:
The workflow state of a risk version in the risk lifecycle, such as draft, in review, approved, or archived.
_Avoid_: monitoring status, work status

**Status Pemantauan**:
The lifecycle state of a risk's monitoring for the active or selected monitoring cycle.
_Avoid_: risk status, latest historical monitoring status

**Siklus Pemantauan**:
The semester period used to decide whether a risk has been monitored for the currently relevant monitoring window.
_Avoid_: latest period, arbitrary review date

**Terakhir Dipantau**:
The timestamp of the most recent finalized monitoring transaction for a risk.
_Avoid_: last updated, draft activity time
