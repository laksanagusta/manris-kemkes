## Context

### Original Request
Ubah template bulk create risiko supaya sama persis seperti Sheet 2 ("KK Penilaian Risiko") pada export kertas kerja. Template dimulai dari cell A1. Seluruh proses server-side.

### Interview Summary
**Key Discussions**:
- Extra columns (Deskripsi, Kategori Risiko, PIC RPR, Unit Kerja): **Ikut Sheet 2 presisi — no extra columns**
- Computed fields (BOBOT, NILAI, TINGKAT RISIKO, PRIORITAS RISIKO): **Kosong/di-formula, server calculates**
- PENGENDALIAN format: **3 kolom (URAIAN, EFEKTIF, TIDAK EFEKTIF) — ikut Sheet 2**
- NO column: **Gak usah ada — auto-numbered by parser**

**Research Findings**:
- Current template (`bulk_preview.go`): 24 flat columns, no styling, 2 sheets
- Target template (`working-paper-export.ts` `buildPenilaianRisikoSheet()`): 4-row merged headers, styled, Bookman Old Style font, gray fills, thin borders, frozen panes
- Backend uses excelize v2; frontend uses ExcelJS (not touching)
- Key missing fields: Deskripsi, Kategori Risiko, PIC RPR, Unit Kerja → backend defaults needed

### Metis Review
**Identified Gaps** (addressed):
- OrganizationID resolution for non-unit users: Add `organization_id` query param to batch preview/create endpoints
- Category default: Default to "operasional" when column absent
- Description default: Default to empty string when column absent
- Mitigation owner: Make optional (empty string when absent)
- Kode Risiko: Include in template but skip in parser (auto-generated by system)
- Backward compatibility: Clean break — new format only
