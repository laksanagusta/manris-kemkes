## Dependency Notes

- **006 must be first** — plans 001 and 003 reference `ease-(--ease-out)` tokens defined in 006.
- **001 and 003 are independent of each other** — they modify different lines in sidebar.tsx and won't conflict.
- **005 is the highest-effort plan** — it involves structural CSS changes. Apply it last or skip if timeline is tight.
- **002 and 004 are independent** — they modify different parts of sidebar.tsx and can run in any order after 006+001+003.
- **007 is fully independent** — it modifies app-sidebar.tsx, not sidebar.tsx.

## Applying Plans

Each plan is self-contained. Apply by following the Steps section in the plan file. After applying:
1. Run `npm run build` (from `frontend/`)
2. Run `npm run lint`
3. Perform the feel checks described in each plan's Verification section
