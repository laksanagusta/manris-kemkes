# Manris design system

## Source of truth

Manris uses the official shadcn/ui `radix-nova` components, Radix primitives, a neutral base color, Inter typography, and Lucide icons. `frontend/components.json` records the component style and base; `frontend/src/app/globals.css` holds the theme tokens and `frontend/src/app/layout.tsx` loads Inter. Files under `frontend/src/components/ui` that come from the shadcn registry must match the source component. Install or refresh them with the project shadcn CLI. Do not add application variants, styles, or business logic to those files.

The living component catalog is `/design-system`. Update this document and that page before changing a shared visual rule on a feature page. After a feature page receives a direct design change, sync both references.

## Toast notifications

All transient toast notifications use [Sonner](https://github.com/emilkowalski/sonner), installed with `npm install sonner` in `frontend`. Import `toast` directly from `sonner` in client code and select `toast.success`, `toast.error`, `toast.info`, or `toast.warning` to match the outcome. Use `toast.promise` for asynchronous loading that resolves to success or error; do not leave loading toasts unresolved. Optional `description` supplies actionable details.

Mount exactly one shared `Toaster` from `@/components/ui/sonner` in the root layout, inside the theme provider. Keep the existing neutral shadcn surface, Lucide status icons, bottom-right position, stacking and dismissal behavior, and application theme support. Feature pages and the design-system catalog trigger this global Toaster instead of mounting their own. Required field validation remains inline. Interactive examples live in `/design-system`.

## Settings modal

Settings opens a centered two-column Dialog above the current page. Use a viewport-safe 1100px maximum width and 82svh height, a 240px desktop navigation column with search, and an independently scrolling content panel. On mobile, stack the search and menu above the content. Keep the stock Dialog surface, close control, focus trap, scrim, and Escape behavior. The navigation group label is “Pengaturan”. The active settings menu item keeps its selected surface and uses `text-primary` for its label and icon; inactive items use `text-secondary-foreground`. Account contains profile details, while Keamanan is a separate menu item containing password controls and an active-device row with a local CC0 MacBook mockup asset, current-device badge, browser, and activity details. Security rows share the Account list pattern: one Card, label/detail alignment, separators between rows, and the same 14px body-label scale; password guidance below the fields uses 12px `text-tertiary-foreground`. Account profile rows align labels left and controls right on desktop, and stack on mobile. Preferences contains the persisted light, dark, and system theme selector; its “Tampilan” section heading sits above the Card, matching the Account section pattern. The Pengaturan entry point opens Account; legacy `/account` and `/settings` links open the same modal on Overview.

The active-device mockup is stored at `frontend/public/device-mockups/macbook-air-silver.svg`, sourced from [PommePlate](https://github.com/ephread/PommePlate) under CC0 1.0.
