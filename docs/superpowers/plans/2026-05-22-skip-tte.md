# Skip TTE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `skip_tte` flag to working paper creation that marks all signatories as skipped and sets the paper to `completed` without electronic signatures.

**Architecture:** Add a boolean `tte_skipped` column to `working_papers` table. When `skip_tte: true` is sent during creation, the working paper is set to `completed` immediately, signatories remain `pending` without QR data, and the risk approval validation is bypassed. Frontend adds a toggle on the create form and adjusts the detail view, export, and view model to show "Dilewati" state.

**Tech Stack:** Go (Fiber), PostgreSQL (pgx), Next.js 16, TypeScript, React Hook Form + Zod, shadcn/ui, Recharts

  const nextSignatory = getNextSignatory(workingPaper);
  const risks = workingPaper.risks ?? [];

  const tteSkipped = workingPaper.tte_skipped;

    canDelete: workingPaper.status === "draft",

    timeline: workingPaper.signatories.map((signatory) =>
